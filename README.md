### 게임 소개
한때 자비로운 성품으로 사랑받고 축복받은 존재로 여겨지던 왕이 있었다. 그러나 저주받은 황금 왕관에 의해 타락하여 탐욕스러운 폭군으로 변해버렸고, <br/>
백성들에게 고통을 안긴 채 군대와 보물과 함께 홀연히 자취를 감추었다. 시간이 흐르면서 폭군도, 그의 보물도 모두 전설 속으로 사라져갔다. <br/>
이 이야기를 책에서 읽게 된 고고학자 은하는, 사라진 왕과 숨겨진 보물의 진실을 밝히기 위해 탐험을 떠나게 된다.<br/>
